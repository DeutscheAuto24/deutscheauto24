### DeutschesAuto24.de

This repository contains the website files for **deutschesauto24.de**, a platform for local vehicle purchasing (Autoankauf) services in Germany. 

### 📁 Repository Overview

* **City Landing Pages**: Individual folders for each target city (e.g., Berlin, Bielefeld, Bochum) containing localized landing pages.
* **SEO Structure**: Optimized static HTML files designed to target local search results across different German regions.
* **Hosting**: Deployed and hosted directly via Netlify.
